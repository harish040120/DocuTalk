# DocuTalk (Static Space)

An in-browser document chatbot. Upload a PDF, ask questions, and get answers grounded in
the document — all running client-side, calling the **free Hugging Face serverless Inference
API**. No backend server, no per-user API key, no subscription.

## How it works

- **PDF text extraction** happens in your browser with [pdf.js](https://github.com/mozilla/pdf.js).
- **Retrieval** is a lightweight keyword-overlap scorer over in-memory text chunks (no extra API calls).
- **Answers** are generated by an open chat model on the HF Hub (default
  [`HuggingFaceH4/zephyr-7b-beta`](https://huggingface.co/HuggingFaceH4/zephyr-7b-beta)) via the
  serverless Inference API. The Space makes anonymous requests by default; paste your own HF
  token in the UI for higher rate limits.

## Files

- `index.html` — UI
- `styles.css` — styling
- `app.js` — PDF parsing, retrieval, and HF API calls

This Space is the deployable UI for the [DocuTalk](https://huggingface.co/docs) project. The
full project (including the Chainlit/Docker version) lives alongside it in the repository.
